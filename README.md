# # Java User & Permission Management

## About
A university project developed using Java to demonstrate Object-Oriented Programming (OOP) and Role-Based Access Control (RBAC) through a campus incident management system.

## Features
- User roles and permission management.
- Role-based access control.
- Incident viewing and closing permissions.
- Encapsulation and object-oriented design.

## User Roles
- **STUDENT:** View own incidents.
- **ANALYST:** View all incidents.
- **ADMIN:** View and close incidents.

## Technologies
- Java
- OOP
- Enum & EnumSet

## How to Run
1. Clone the repository.
2. Open the project in NetBeans.
3. Run `CampusIncidentVault.java`.
